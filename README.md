# Workshop Exercises

This repository contains the hands-on exercises selected for your workshop. Each exercise links to its corresponding slides for supporting concepts and instructions.

## Getting Started

```bash
npm install
```

## Exercises

- [`react`](exercises/react) — [Slides](https://tkmaxx-workshop.vercel.app/react)
- [`fundamentals`](exercises/fundamentals) — [Slides](https://tkmaxx-workshop.vercel.app/fundamentals)
- [`rendering`](exercises/rendering) — [Slides](https://tkmaxx-workshop.vercel.app/rendering)
- [`caching`](exercises/caching) — [Slides](https://tkmaxx-workshop.vercel.app/caching)

> **Note:** All exercises run on port 3000. Only run one exercise at a time.

Run a single exercise:

```bash
cd exercises/<exercise-name>
npm run dev
```
